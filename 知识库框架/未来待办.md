# 未来待办

## Summary

Sunday Note 当前已经进入 v0.1 框架验证阶段。下一步重点不是继续增加能力，而是验证真实使用闭环、减少规则膨胀、稳定 agent skill 边界。

## v0.1 验证重点

- 连续真实使用一到两周，观察 Daily、Weekly、Monthly、Project、Wiki 是否能形成闭环。
- 保持 `AGENTS.md` 简洁，只维护目录职责、信息架构、写入边界、图像文件和维护边界。
- 验证 `sunday-note-ingest`、`sunday-note-query`、`sunday-note-lint` 三个 micro-skill 是否覆盖真实维护流程。
- 暂不把 Canvas、imagegen、Workbench 或新插件纳入主线。

## Skill 验证

- `sunday-note-ingest` 负责把外部资料或 Raw 转化为可判断、可追溯的候选，并在用户确认后提出 canonical Wiki 合并建议。
- `sunday-note-query` 负责基于已有 vault 内容回答问题，并标明依据和不确定性。
- `sunday-note-lint` 负责检查重复主题、孤立页面、未索引页面、过期内容、弱链接和边界混淆。

## 后续判断

如果以后发现三个 skill 重复过多，再考虑抽取共享 reference；暂不合并成一个总 skill。

- ingest、query、lint 已经连续使用至少两周。
- lint 已经形成稳定指标表。
- ingest 和确认后 compile 的边界已经稳定。
- 需要脚本辅助检查孤立页面、缺 sources 页面或过期项目。

## Git 边界检查

后续需要持续检查 `.gitignore` 和实际仓库是否一致，尤其是：

- `.obsidian/workspace.json`
- 个人图片和附件
- Terminal transcript
- 模板正文
- `30_知识库/` 下的正文知识
- `40_个人写作/` 下的个人写作

框架参考知识可以单独放行，但不要打开整个知识库正文的提交口子。
