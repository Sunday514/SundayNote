# 个人上下文

## 工作流

1. 读取根目录 `个人上下文.md` 和 `AGENTS.md`。页面没有已确认正文时执行初始化；已有内容时在统一模板内校准用户指定的部分。
2. 初始化时按顺序完成兴趣与经验、价值取舍、证据与知识演化、判断与协作、表达偏好五个维度。严格按照下列问题顺序，每轮只展示一个问题并等待一个完整回答后再继续；允许跳过、提前结束或取消，跳过第 3 题时同步跳过第 4 题。只在回答矛盾或无法提炼时追加澄清，最多两题。
3. 使用 `assets/个人上下文.md` 的完整结构，根据问题、回答和已有内容生成草案。对提到的长期领域、项目和记录类型，只在现有 Wiki、项目汇总或索引有可靠信息时写入检索词、关系和入口；没有时不推测。不保存问答过程或项目进度。
4. 根据完整个人上下文提炼一段个性化响应 prompt，说明 agent 面对用户请求时怎样判断、表达和协作；同时链接完整个人上下文。
5. 同时展示完整页面和完整个性化响应段。用户提出修改时重新生成两份草案；只有用户一次明确确认两份草案后才同时写入。

## 问题

初始化时使用以下问题。把 `【真实任务】` 替换为用户此前回答或已有个人上下文中的一项真实任务；没有可用任务时改为“你熟悉的一项真实任务”。除此之外不改变题意，不合并问题，也不提前展示后续问题。

### 兴趣与经验

#### 1. 长期任务

> 想象未来三到六个月，你最可能反复讨论或交给我的 2–4 类真实任务或项目是什么？为什么它们值得你持续投入，而不只是一次性需求？

#### 2. 经验与交流起点

> 以 `【真实任务】` 为例：你亲自处理过哪些部分？以后讨论这个任务时，我应从入门解释、按熟悉者交流，还是把你当作可以直接质疑和挑战的合作者？

### 价值取舍

#### 3. 真实取舍

> 回想你在 `【真实任务】` 中最近一次没有标准答案、必须放弃一部分目标的决定：当时真正冲突的两个目标是什么，你最后选择了哪一边，又实际牺牲了什么？

#### 4. 切换条件

> 对刚才的取舍，如果风险、成本、时间压力或对他人的影响发生什么变化，你会改选另一边？请给出最关键的分界条件。

#### 5. 处理价值冲突

> 面对包含价值冲突、没有纯事实答案的问题，你希望我们默认从哪一步开始：明确各方实际牺牲了什么、识别不可接受的底线，还是提出一个可执行的暂定选择？请选择默认起点，并说明什么时候应该换一种方式。

### 证据与知识演化

#### 6. 新材料与旧结论冲突

> 当新材料与知识库已有结论冲突时，你希望我默认怎样处理：保留并列解释、指出关键分歧后给出暂定判断，还是在证据足够时直接提出修正旧结论？请选择你希望采用的默认顺序。

#### 7. 形成暂定判断

> 当证据还不完整，但继续罗列观点已经不能推进思考时，你希望我在什么条件下给出暂定判断？这个判断应怎样标明依据、未知部分和可能改变它的新证据？

### 判断与协作

#### 8. 提出异议与推动修正

> 当你的已有判断、知识库结论或我的推论受到可靠反例挑战时，你希望我怎样提出异议并推动修正？请描述默认步骤，使我既不迎合你，也不把分歧简化为一句“存在争议”。

### 表达偏好

#### 9. 直接程度

> 下面两句只比较直接程度，你更愿意读哪一句？A「这个方案值得做；先把范围缩小到一周内可验证的版本」；B「这个方案可以考虑；或许先把范围缩小到一周内可验证的版本」。请说明原因；如果选择取决于任务，也请给出分界线。

#### 10. 术语密度

> 下面两句只比较术语密度，你更愿意读哪一句？A「先做小范围测试，确认结论在不同情况下都成立，再扩大使用」；B「先做局部验证，确认结论具备跨情境稳健性，再扩大应用」。请说明原因；如果选择取决于任务，也请给出分界线。

这些问题只用于提炼用户明确表达的长期上下文。不计算分数，不诊断人格，不根据示例选项推断用户没有说明的偏好；系统安全、事实真实性和 vault 权限不随个人偏好改变。

## 输出

`个人上下文.md` 使用 `assets/个人上下文.md` 的全部标题。正文只保存稳定、已确认、能指导后续任务的简练信息和实际存在的页面链接；不保存访谈流水、题号、评分、项目进度、临时情绪、心理标签或未经确认的推断。

个性化响应段使用以下结构：

```markdown
<!-- sunday-note:personal-context:start -->
## 个性化响应

个人上下文：[[个人上下文]]

<一行且不换行的行为 prompt 段落>
<!-- sunday-note:personal-context:end -->
```

prompt 从完整个人上下文提炼，直接指示 agent 如何回答，不复述“用户喜欢什么”或压缩个人画像。当前请求始终覆盖长期偏好；事实、证据、风险或约束冲突时明确提出异议。

## 写入

- 根 `AGENTS.md` 中两个标记都不存在时，在文件末尾追加完整个性化响应段；恰好有一对顺序正确的标记时替换整个标记块。标记残缺、逆序或重复时停止写入。
- 任一文件无法安全修改时都不写。取消、沉默或含糊确认不写文件；普通对话中的风格反馈不自动积累。
